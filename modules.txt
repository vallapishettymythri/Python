Module- 
module is any python file with ".py" extension.
Module will contains the functions and its definations.

We have two types of modules.
1.Pre-defined/built in- These modules are already available in 
programming language.
syntax:
import module_name
eg-
import math
import os

How to access the functions present in the module?
module_name.function_name()
