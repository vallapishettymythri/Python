We have exception handling blocks are
1.try
2.except 
3.finally

Try-It is having a risky code. We will keep that code which can raise the exception.

Except- Handling code. If a exception is getting raise this block will handle the exception.
If there is exception then only except block is getting executed. Otherwise it will not be executed.


Finally- It is just for cleanuo or refresh purpose. Weather the exception raised or not the finally is execute.
